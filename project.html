GeoScan Attendance Pro

Project Overview

GeoScan Attendance Pro is a smart QR code and GPS-based attendance system designed to make attendance tracking more accurate, secure, and efficient.

The system uses dynamic QR codes and GPS verification to ensure that attendance is recorded only when students are physically present in the correct location during an active session.

Project Objectives

  • Develop a secure web-based attendance management system.
  • Use dynamic QR codes for attendance authentication.
  • Use GPS verification to confirm the student's location.
  • Reduce proxy attendance.
  • Store attendance records in a centralized database.
  • Provide attendance reports and analytics.

System Features

  • User login
  • Dynamic QR code generation for each class
  • QR code scanning for attendance
  • GPS location verification
  • Real-time attendance tracking
  • Role-based dashboards
